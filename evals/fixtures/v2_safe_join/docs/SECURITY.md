# 路径安全约定

`safe_join(base, user_path)` 把用户提供的相对路径拼到存储根目录 `base`（POSIX 风格路径）下：

- 结果必须位于 `base` 之内（或就是 `base` 本身）。`a/../b` 这类最终仍在 `base` 内的路径是合法的。
- 以下情形一律抛出 `ValueError`：绝对路径、解析后跑出 `base` 的路径、包含空字符 `\x00` 的路径。
- 反斜杠 `\` 也按路径分隔符处理（因为上游会把 Windows 风格路径传进来）。
- 注意"前缀相同的兄弟目录"：`base` 为 `/srv/data` 时，`../data2/x` 解析为 `/srv/data2/x`，这在 `base` 之外，必须拒绝。
- 空路径返回 `base` 的规范化形式。
