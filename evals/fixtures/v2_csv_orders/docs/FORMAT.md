# 订单 CSV 格式

- 第一个非空行是表头，必须包含 `id`、`customer`、`amount` 三列。列名**不区分大小写**，列顺序任意，列名两侧空白忽略。
- 字段遵循 RFC 4180：可用双引号包裹，被包裹的字段内可含逗号。
- 完全空白的行直接忽略。
- 金额是十进制字符串（如 `19.99`），最多两位小数，转换为整数"分"（`1999`）。必须精确，不得经过二进制浮点；
  超过两位小数时抛出 `ValueError`。
- `id` 在文件内必须唯一；重复时抛出 `DuplicateIdError(order_id, line)`，其中 `line` 为第二次出现的那一行的行号
  （文件第 1 行为 1，空行也计入行号）。
- 缺少必需列时抛出 `MissingColumnError(column)`。
- 空文本返回空列表。
