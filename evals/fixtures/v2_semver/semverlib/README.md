# semverlib

`Version(text)` 解析 `MAJOR.MINOR.PATCH[-prerelease][+build]`，遵循 SemVer 2.0 的优先级规则：

1. 先按 major、minor、patch 的**数值**比较。
2. 带预发布标识的版本**低于**同一 major.minor.patch 的正式版。
3. 预发布标识以 `.` 分隔后逐段比较：纯数字段按数值比较；含字母的段按 ASCII 字典序；
   纯数字段**低于**含字母的段；前面各段都相同时，段数少的低于段数多的。
4. 构建元数据（`+` 之后）不参与比较：`1.0.0+a` 与 `1.0.0+b` 视为相等（`==` 为真，且哈希相同）。
5. 非法版本（缺少某一段、数字段有前导零如 `01.0.0`、空预发布段等）抛出 `ValueError`。
6. 支持 `<`、`<=`、`>`、`>=`、`==`、`!=` 与 `sorted()`。
